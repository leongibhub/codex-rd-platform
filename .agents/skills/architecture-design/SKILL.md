# Architecture Design

Flow:
Context → Requirements → Constraints → Options → Trade-offs → Decision → Design → ADR → Review.

Do not pick technologies merely because they are familiar.
For material decisions document alternatives, rationale, consequences, risks, and reversibility.
Trace design items back to REQ/NFR IDs.
