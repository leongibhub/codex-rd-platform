# Task Breakdown

Each TASK must include:
- TASK-ID
- linked REQ/NFR/DES
- objective
- dependencies
- explicit scope
- allowed files / areas
- forbidden areas where useful
- implementation constraints
- acceptance criteria
- required tests
- verification commands
- deliverables

Prefer tasks small enough for isolated branch/worktree ownership.
