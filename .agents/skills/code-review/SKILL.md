# Review

Classify:
- P0 blocker
- P1 critical
- P2 major
- P3 minor

Each finding needs:
- affected requirement/task where known
- file/symbol or evidence
- failure mode
- impact
- reproduction/validation where possible
- recommended remediation

Do not approve unresolved P0/P1.
