# Testing

Derive tests from:
PRD + REQ/NFR + interfaces + acceptance criteria + risks.

Each test case should include:
- TC ID
- linked requirement
- objective
- preconditions
- environment
- data
- exact steps
- expected result
- actual result
- evidence
- status
- linked defects

PASS only on executed, observable evidence.
