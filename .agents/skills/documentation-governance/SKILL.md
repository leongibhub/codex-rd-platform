# Documentation Governance

Continuously validate:
BG → PRD → REQ/NFR → DES/ADR → TASK → change/commit → TC → BUG → REL.

For each Gate:
1. enumerate required artifacts;
2. confirm they exist;
3. check internal consistency;
4. check evidence-backed fields;
5. update RTM;
6. report PASS / FAIL / BLOCKED.

Never synthesize fake approvals or test outcomes.
