# Requirement Analysis

For each requirement:
- assign stable ID
- state source/rationale
- define behavior
- define normal/exception/boundary behavior
- define dependencies/constraints
- define measurable acceptance criteria
- define verification method

Perform:
- ambiguity check
- conflict check
- completeness check
- testability check
- NFR coverage check

Update `docs/03-requirements/requirement-traceability-matrix.md`.
