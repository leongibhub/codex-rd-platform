# Competitor Analysis

Build a comparison based on evidence rather than marketing claims alone.

For each competitor capture:
- target customer
- key scenario
- core capabilities
- differentiators
- limitations
- ecosystem/integration
- commercial model if verified
- evidence/source/date
- implications for this project

Write/update `docs/01-research/competitor-analysis.md`.
