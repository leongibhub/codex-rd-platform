# REL-001 — v0.1.0-preview.1

## 中文：首个宿主协作版预览

**Preview / Pre-release，仅供开发者评估，不是生产稳定版或项目 G10 验收。**

把 AI 编程变成可观测的软件工程：面向 Codex 的多 Agent 研发工作台，提供 9 个专业 Agent 定义、14 个可复用 Skill、统一编排入口及真实任务/测试/审查证据管理。

### 本版本提供

- `platform-orchestration` 统一入口：从粗略需求分析、关键问题澄清到分模块开发与交付。
- 9 个专业角色与 14 个 Skill；开发、独立测试和审查分离，按任务选择，不是同时启动 9 个模型。
- 本地 SQLite Runtime 与 loopback 看板：项目、Agent、Task、Run、阶段前提、事件和交接可观察。
- 版本化工件、需求追踪、测试模型/用例/执行、缺陷修复闭环和证据驱动的阶段门禁。
- 受控 worker-service、租约/心跳/取消与恢复、SSH Ed25519 审批适配器、部署/健康检查/回滚执行接口。
- Windows 与 Linux 安装脚本；C++、Python、Web、Java、微信示例的多技术栈执行工具链。
- 中英文安装、Skill 调用、续作、看板、操作与限制说明。

### 获取与开始

本次发布固定源码提交：`4a7df0dfc5b2f7fc8aacef197bea4b0aeaadf7db`。

```sh
git clone --branch v0.1.0-preview.1 --single-branch https://github.com/leongibhub/codex-rd-platform.git
cd codex-rd-platform
git switch -c my-preview-evaluation
```

先读 [中文 README](https://github.com/leongibhub/codex-rd-platform/blob/v0.1.0-preview.1/README.md) 或 [English README](https://github.com/leongibhub/codex-rd-platform/blob/v0.1.0-preview.1/README.en.md)，按其中前置条件配置本仓 Git 身份与 Python 3.11+，再运行 `scripts/setup.ps1`（Windows）或 `bash scripts/setup.sh`（Linux）。README 的持续开发分支获取方式与上述固定版本获取方式是两种选择。

在 Codex 打开平台仓库，确认 Skill/角色实际可用，然后在聊天框输入：

```text
使用 platform-orchestration，帮我开发一个内部测试管理系统，放在独立的应用目录。
先分析需求并只问关键问题，再分模块实现、独立测试与审查；在看板展示真实工作。
```

Skill 是宿主工作方法，不是可脱离仓库/Runtime 单独运行的服务。仅复制一个 SKILL.md 不会安装整个平台。
