# Requirement Traceability Matrix

|---|---|---|---|---|---|---|---|---|---|

## Coverage Rules
- Every in-scope REQ/NFR must link to acceptance criteria.
- Every implemented REQ/NFR must link to design/task/change evidence.
- Every releasable REQ/NFR must link to independent verification evidence.
- Missing links must be explicit; never infer PASS from implementation alone.
