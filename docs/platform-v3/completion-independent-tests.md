# CR-V3-003 / CR-V3-004 independent execution-endpoint test model

- Scope: `REQ-V3-016` through `REQ-V3-020`; tasks `TASK-V3-016` through `TASK-V3-020`, including the security-model replacement in [CR-V3-004](CR-V3-004-safe-model-execution.md).
- Test owner: independent tester (`/root/completion_qa`), separate from module implementation owners.
- Test basis: [completion execution design](completion-execution-design.md), [CR-V3-004](CR-V3-004-safe-model-execution.md), public Runtime/HTTP/CLI interfaces, and the failure risks below. Developer unit tests are not evidence for this record.
- Environment: local Windows host, Python 3.11+, isolated temporary SQLite databases and workspaces; real local subprocesses and real loopback HTTP only. No production credentials, customer approval, remote deployment, or Git private key is used.
- Evidence rule: a `PASS` requires the listed command to complete with observable assertions. A test not run is `NOT EXECUTED`; it is never inferred from code or developer claims.
