# Python CSV 费用分析工具：初始模型

状态：DRAFT；来源：`REQ-MATRIX-PY`（`docs/superpowers/specs/2026-09-06-multistack-selftest.md`）。本文件是开发者对粗需求的可逆解释，不构成审批或最终验收。

## 目标与使用者

为本地命令行使用者读取一份 UTF-8 CSV 费用数据，并得到可由程序继续消费的类别汇总和总额 JSON。范围仅限单次本地分析；不保存数据、不访问网络、不接入账户或外部服务。

## 工作流和数据

使用者执行 `python expense_analyzer.py <csv-path>`。输入的首行是列名，必须恰含 `date`、`category`、`amount` 三列（允许列顺序不同）；每个数据行必须提供非空日期、类别和金额。输出为单个 JSON 对象，类别键按字典序排列，金额以十进制字符串表示，避免 JSON 消费者把精确金额转换为二进制浮点数。

## 约束、失败和假设

- 日期采用严格 `YYYY-MM-DD` 日历日期；空文件、只有表头的文件、错误表头、缺失/多余字段、空类别、坏日期和坏金额均失败。
- `amount` 采用 `Decimal`；负值、NaN、sNaN、Infinity 和 -Infinity 失败；零值在原始范围未禁止，因此计入汇总。
- 读取使用 `utf-8-sig`，兼容普通 UTF-8 及可选 BOM。输出 UTF-8 JSON；错误写入 stderr 且进程返回非零，不输出部分 JSON。
- 不处理多币种、税、时区、日期区间筛选、CSV 修复或持久化；它们不在 REQ-MATRIX-PY 范围内。

## 可测验收解释

有效 CSV 的每个类别精确相加且总额等于所有有效金额之和；`0.10` 与 `0.20` 的结果必须为 `0.30`。任一拒绝条件必须产生明确错误和非零退出，并不得返回成功 JSON。
