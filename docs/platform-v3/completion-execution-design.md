## 边界与集成

执行端新增独立模块，不重写 migration 1。调度通过 Runtime work 租约而非另建任务真相源；进程本身不是 Agent 身份认证，任务输出需 Runtime 校验。宿主配置为可信执行配置，不接受匿名 HTTP 任意 argv。不同专业阶段用不同实际执行实例；质量 Gate 仍由测试/审查链决定。

审批采用独立身份/公钥信任配置；平台只验证，签名操作由真实操作者的隔离客户端完成。无配置默认拒绝。配置目录由服务操作员保护，非多租户敌对代码沙箱。

部署适配器采用显式 argv + 独立健康检查，支持本机试用环境和受授权远端工具命令。拒绝隐式生产地址；健康失败执行预先声明补偿。试用结果域与正式 REL/Gate 域分离。服务重启时保留未完成操作，不盲目重复非幂等命令。
