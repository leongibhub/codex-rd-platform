## 实施约束

保留已有代码和历史记录；各任务独占文件，并行开发后独立测试、审查。容量使用合成数据库记录，明确不等于 API 写入吞吐量；非功能预算由测量事实决定，不编造目标达成。SQLite 运行库不是 Git 交付物，导出经脱敏检查才提交。当前平台仍由真实 Codex 宿主派发 Agent，不把数据库中的工作单当成后台模型服务。

优先完成上述本地可验证的能力；真实认证审批适配器、受控部署适配器和宿主调度集成按其实际实现证据继续补齐。人员身份绑定、真实批准、微信开发工具/账号和生产目标必须有真实外部事实，不能以模拟替代。未完成项必须写明具体工程缺口和下一步，不再仅列“愿景边界”。
